# Strategy2Code
In this project, we are trying to find methods that can transfer quantitative finance papers to codes.   
README.md files of each sub-files include detailed descriptions of the sub-files. 

## Chat Agent
`agent/chat_agent.py` adds a chat-style interface that can:
- run the Strategy2Code pipeline,
- evaluate generated code,
- verify execution status,
- explain what generated code does and how to run it.

Quick start:
```bash
python agent/chat_agent.py --interactive
```
